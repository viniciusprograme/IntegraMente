✅ Como Testar Responsividade

  1. Abra o navegador com F12 (DevTools)
  2. Pressione Ctrl+Shift+M para ativar "Device Toolbar"
  3. Alterne entre diferentes dispositivos (iPhone, Samsung, iPad, Desktop)
  4. Redimensione manualmente a janela para ver transições suaves
  5. Verifique que elementos se adaptam sem quebrar layout
  6. Teste em múltiplos navegadores e dispositivos reais
